# Archivo Cronológico — Desguaces VFU — Alvale Consulting

Genera el Archivo Cronológico de Retiradas de Residuos para gestores de
Vehículos al Final de su Vida Útil (VFU) a partir del Excel de Ingurunet.

## Descarga del EXE

1. Ve a la pestaña **Actions** del repositorio
2. Selecciona **Build Windows EXE** → **Run workflow**
3. Cuando termine, descarga el artefacto **Archivo_Cronologico_Desguaces-Windows**

## Uso

1. Coloca `Archivo_Cronologico_Desguaces.exe` y `logo_alvale.png` en la misma carpeta
2. Ejecuta el `.exe`
3. Selecciona el Excel de Ingurunet y la ruta de salida del HTML
4. Pulsa **▶ GENERAR**
5. Se abrirá el navegador → `Ctrl+P` → Guardar como PDF

## Requisitos del Excel

- Hoja **`DATOS EMPRESA`** con los datos del centro
- Hoja **`REGISTRO SALIDAS`** con los registros desde la fila 3
